Supply Chain Delivery & Profitability Analysis

A data analytics and machine learning project analyzing e-commerce supply chain performance, delivery delays, profitability, operational bottlenecks, and late-delivery risk using the **DataCo Smart Supply Chain Dataset**.

Project Overview
This project explores the operational performance of a global e-commerce supply chain and answers three key questions:
- Where and when are delivery delays occurring?
- What operational factors are associated with late deliveries and profitability?
- Can machine learning be used to identify orders at risk of late delivery?

The project covers:
- Data cleaning & preprocessing
- Exploratory Data Analysis (EDA)
- KPI analysis
- Profitability analysis
- Delivery-delay analysis
- Bottleneck & root-cause analysis
- Time-based analysis
- Late-delivery prediction using Random Forest
- Class-imbalance handling using SMOTE
- Business recommendations

Key Results
Metric - Result 
Orders analyzed - 172,765 
Late deliveries - 94,523
Late delivery rate - 54.71% 
On-time delivery rate - 45.29% 
Total profit from profitable orders - $7.5M 
Profit associated with delayed orders - $2.1M 
Random Forest accuracy - 74% 
Late-delivery precision - 79%
Late-delivery recall - 75% 

The $2.1M figure is an exposure/profit-at-risk proxy, not an estimate of profit causally lost due to delays.
